# 목표
- 사진(*.jpg, *.png, ... 등) 파일을 여러장 넣으면 모두 pdf화 할 수 있는 프로그램 만들기

# 기능
- 한 *.exe 파일을 만들고, gui를 통해 내가 이미지를 끌어다 놓으면 바로 pdf화 해줌
- 드래그 앤 드롭으로 추가한 이미지 순서를 목록에서 바로 재정렬
- 선택한 이미지만 삭제 가능
- 중복 파일/지원하지 않는 파일은 자동 제외하고 안내 문구 표시
- 저장 후 방금 만든 PDF를 버튼으로 바로 열기 가능
- 이미지가 없을 때 저장 버튼 비활성화 등 기본 상태 제어

# 예시
- iLovePDF, SmallPDF, ... 등

# 다음 후보 기능
- 이미지 to PDF / PDF 병합을 시작 화면의 모드 버튼으로 분리
- PDF 분할, 특정 페이지 추출, 회전
- A4 외 용지 크기, 여백, 세로/가로 옵션
- 압축 품질 선택, 파일 크기 줄이기
- 변환 진행률 표시

# 에러
- 배포할 때 문제가 발생함. 똑같이 따라해도 파워쉘 등 설정을 해야하는 문제가 있음
