# App Icon Guide

이 폴더에 아래 파일 중 하나를 넣으면 앱 아이콘으로 자동 반영됩니다.

- `app_icon.ico`
- `app_icon.png`

권장 순서:

1. Windows 배포용으로는 `app_icon.ico`
2. 앱 실행 중 창 아이콘 미리보기용으로는 `app_icon.png`

## 권장 아이콘 방향

- 문서 느낌의 `A4 페이지` 실루엣
- 오른쪽 아래 또는 중앙에 `PDF` 포인트
- 보조 요소로 `사진/이미지`를 뜻하는 작은 프레임 또는 산 아이콘
- 색상은 현재 앱 톤에 맞게 `블루 + 화이트 + 약간의 민트`

## 권장 제작 규격

- 원본: `1024x1024`
- 내보내기: `256x256 PNG`
- Windows용 변환: `256, 128, 64, 48, 32, 16` 사이즈 포함 `.ico`
